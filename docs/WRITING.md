# 用写作台编辑 Markdown

打开 [写作台](https://st0lyp1n.github.io/studio/)，也可以从侧栏进入。

## 拖入文件

把 `.md` 或 `.markdown` 文件直接拖进页面；手机上点击“拖入 .md 文件”即可选择文件。

- 支持一次选择多个文件。
- 支持 UTF-8 编码，单个文件最大 2 MB；正文最多 1,500,000 个字符。
- 自动识别普通 Markdown、YAML `---` 和 TOML `+++` 文章信息。
- 同名文件作为独立草稿保留，不覆盖之前导入的内容。
- 导入和编辑不会修改磁盘上的原文件。

## 编辑和预览

标题与简介直接填写。展开“文章信息”可修改日期、文件名、分类、标签和草稿状态。导入文件的其他字段，如 `math`、封面和自定义配置，会保留到导出的文件中。

正文支持标题、加粗、斜体、链接、引用、代码块、列表、任务清单和表格。工具栏可插入相应语法，并支持正文撤销/重做。

- 桌面默认双栏：左侧编辑，右侧实时预览。
- 手机默认只编辑，可切换“只预览”或上下双栏。
- “手机预览”收窄预览区域；“专注”隐藏站点导航与草稿栏。
- “同步滚动”让预览跟随编辑区域的阅读位置（按滚动比例，不是逐行映射）。

外部图片在预览中显示说明，不会自动请求第三方服务器。`/images/` 下的本站图片可以显示。本地相对路径图片需另外放入站点图片目录；图片不会跟随 Markdown 自动上传。

预览不执行原始 HTML 中的脚本或嵌入框架。Hugo 短代码和数学公式应在本地 Hugo 构建后查看最终渲染。

## 保存、备份和恢复

编辑后会自动尝试保存到当前浏览器。顶部状态显示保存结果。**自动保存不等于云端备份**：换设备、隐私浏览或清除网站数据，可能丢失本地草稿。

定期点击“备份全部”下载 JSON。通过“恢复备份”选择这个文件，将草稿合并回当前写作台；不会清空已有草稿。备份恢复最大 20 MB，总草稿数量最多 100 篇。

如果顶部出现保存失败提示，请立即导出文章或备份。若两个标签页同时编辑，收到更新的旧标签页会暂停自动保存，防止相互覆盖；先备份旧标签页，再刷新查看新的内容。

## 导出与发布

1. 填写有效标题、文件名、日期与正文。
2. 完成文章后，在“文章信息”里取消“导出为草稿”。勾选时导出的 `draft: true` 不会进入正式构建。
3. 点击“导出 Markdown”，得到带 YAML 文章信息的文件。
4. 把文件放进项目的 `content/posts/`。如果本地存在同名文件，先确认是否要替换。
5. 执行 `npm run dev` 预览，然后提交到 GitHub 的 `main` 分支。
6. GitHub Actions 通过构建、测试后自动部署博客。

**写作台不会直接发布。** 本地草稿与公开站点明确分离，不需要在浏览器里存 GitHub 访问令牌。

## 快捷键

| 快捷键                     | 功能               |
| -------------------------- | ------------------ |
| Ctrl / Command + S         | 导出当前 Markdown  |
| Ctrl / Command + B         | 正文选区加粗       |
| Ctrl / Command + I         | 正文选区斜体       |
| Ctrl / Command + Z         | 撤销正文修改       |
| Ctrl / Command + Shift + Z | 重做正文修改       |
| Ctrl / Command + K         | 全站搜索           |
| Esc                        | 关闭说明或确认弹窗 |
