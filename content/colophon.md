## 设计与构建

本站由 Hugo 生成，部署目标为 [st0lyp1n.github.io](https://st0lyp1n.github.io/)。在原有 PaperMod 仓库基础上使用独立的页面模板与样式，保留 Markdown 写作方式。

设计采用米白、森林绿和细分隔线。正文优先使用系统字体，无需为首页下载字体。页面尊重系统的“减少动态效果”设置，也支持键盘操作与深浅色模式。

## 内容说明

原有的 **Hello World** 文章予以保留。新增文章、随记、书架和近况为功能演示内容，相关页面已标注。展示不代表博主的真实经历、阅读进度或观点。项目页中的工具可以实际使用。

相册为 Unsplash 风景素材，每张照片附有来源，并非博主原创摄影。侧栏的文章、随记与作品数量来自实际内容，没有虚构访问量。

## 隐私与存储

- **阅读收藏、字号、主题、草稿纸**：仅存储在当前浏览器。清除网站数据会删除这些设置，不跨设备同步。
- **搜索**：在浏览器内搜索静态索引，不上传搜索词。
- **评论**：只有点击“加载评论”才连接 Giscus。评论依赖 GitHub 账号和 Discussions 服务，遵循该服务的隐私规则。
- **统计**：本站未安装访客跟踪或广告脚本。
- **公式**：含公式的文章会按需加载 MathJax CDN；网络不可用时保留原公式文本。

## 快捷键

| --- | --- |
| Ctrl / Command + K | 全站搜索 |
